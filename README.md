# Play & Learn Hub

Desenvolva uma plataforma web com cinco jogos educativos projetados para crianças com síndrome de Down. A plataforma deve ser criada utilizando HTML, CSS e JavaScript, com a possibilidade de usar bibliotecas via CDN para animações, desenhos ou efeitos visuais, quando isso for útil.  A equipe desta tarefa é constituída por um pedagogo especialista em síndrome de Down, neuropediatra e web designer senior.
